How to read this page

  • "Not demonstrated" means the registered rule was not met. It is not proof that there is no edge.
  • R is the amount risked on a trade (1% of the account). An expectancy of 0.15 R means the average trade made 15% of what it risked.
  • All tests use the same ten years of data, so each extra test makes a lucky pass more likely.
  • This page is built from the stored result files by docs/results/build_results_page.py. The ledger and each strategy's report are the record.
