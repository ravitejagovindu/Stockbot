## 1. The three differences from family_batch4 run 1 (the only ones)
1. **`STOCKBOT_NON_EQ=held`.** Held positions keep their BE/BZ bars (table `market_data_non_eq`, bar series BE and BZ; BL rows never form a bar) for marks, stops, ATR, reference highs and exits. A restricted stock is NEVER bought: the gates `NOT_EQ_SERIES` (proposal) and `NOT_EQ_SERIES_AT_FILL` (fill) apply to the strategy and to the baseline's random draws alike. The stale rule counts a bar in any series, so `SYMBOL_NO_BARS` fires only when no series has a bar for 20 sessions (`docs/shared/non-eq-series/DESIGN.md` section 4). Eligibility and ADTV still read EQ bars only.
2. **The BE/BZ sell model of `docs/shared/non-eq-series/DESIGN.md` section 5, as built in stage 2:** on a bar of a restricted series a sell fills at most **10% of the bar's volume** per session (the rest is a pending exit at the next session, event `SELL_CAPPED_NON_EQ`), **exit slippage is doubled**, and **nothing fills on a single-price low-volume bar** (high equals low). **A fixed assumption, not evidence**: the 10%, the doubling and the lock rule are the owner's numbers and are not tuned; the files carry no price-band data.
3. **The database file** is the current guarded `finsight.db`; its sha256 differs from `dcade465...b752` (it holds the guard tables and triggers, the table `market_data_non_eq` and rows loaded after 2026-10-16). Every row dated up to 2026-10-16 in every table the run reads is identical to the pre-guard reference file (guard proofs, `Claude_Docs/DB_GUARD_REPORT.md`). The window stays **2016-01-01 to 2026-10-16**, so no row dated after 2026-10-16 is read. The run records the file hash, the correction counter, the sealed dates and the insert-only table digests before and after (`db_check` in the manifest, which must be clean).

## 7. Limitations (additional to PREREGISTRATION.md section 12)
The BE/BZ sell model is a fixed assumption (10% of volume, doubled slippage, lock rule); real BE/BZ liquidity is thin (median BE row 16,015 shares) and there are no price-band data, so BE/BZ outcomes can be better or worse than modelled. Corporate actions in BE/BZ follow the same adjustment code on merged bars. A stock returning to EQ after a long BE spell can pass the ADTV test on old EQ bars (DESIGN Q3, unchanged). Trade symbols are matched to the table by their lake name (renamed stocks carry their latest name). No dividends, EQ-only universe, sector map and ASM/GSM limits are as in batch 4.
