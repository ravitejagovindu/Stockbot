## 2. The rule, in exact words
The rule is riskadj_momentum_daily's code, copied verbatim into `stockbot/strategies/momentum_calm_daily/strategy.py` (a strategy may not import another strategy; `is_signal_session`, `cooldown_symbols`, `assess`, `initial_stop`, `order_signals` and the ATR indicator are identical copies, and a unit test proves that with the filter off the proposals equal riskadj_momentum_daily's, also with a name in cooldown). Definitions, as in that code:
- **Signal sessions:** EVERY session of the calendar; the only condition is that the 252-session calendar window exists (first possible signal 2016-12-01 as before, the earlier months are empty).
- **History guards:** a bar on the signal session; at least 240 adjusted closes inside the last 252 calendar sessions ending at it; 253 adjusted bars of the symbol's own; finite positive closes.
- **Momentum:** r12 = adjusted close[t-21] / adjusted close[t-252] - 1, required **> 0 strictly**. vol = sample sd (ddof 1) of the daily log returns of the consecutive adjusted closes t-252 through t-21, required > 0. **Score s = r12 / vol.** Order: s descending, exact ties by higher raw 20-session ADTV, then symbol. The top 25 are proposed with ordinal rank 25 down to 1.
- **Stop and exit:** initial stop = signal close - max(3 x ATR14, 0.08 x signal close), ATR14 the Wilder ATR on the adjusted high, low, close of the symbol's last 252 bars; a stop at or below zero makes the name unusable. Exit `mcd_trailing_atr3_floor8`: reference = highest close since entry (seeded with the entry price); each session new stop = max(live stop, reference - max(3 x ATR14 of that session, 0.08 x reference)); it never moves down; set on bar T it applies from bar T+1; no time exit.
- **Cooldown:** a symbol whose position of THIS strategy was closed by STOP_HIT is not proposed until 21 sessions have passed after the exit session (the exit session and the 21 sessions after it are blocked; **the 22nd session after the exit is the first allowed**). Only STOP_HIT starts it (SYMBOL_NO_BARS, operator-reported reasons and everything else do not; END_OF_WINDOW never reaches the strategy). The exits come only from the engine-owned history in `strategy_state["_exits"]`, the sessions from the calendar; linked names are the same symbol.
- **THE ONE NEW ELEMENT, the calm filter (identical to momentum_calm).** On each session t, **sigma252** = sample standard deviation (ddof 1) of the **252 daily log returns of the symbol's own consecutive adjusted closes t-252 .. t** (the last 253 own bars). It is computed for **every eligible name that passes the history guards** (the names that have a sigma252), **before** the r12 > 0 filter **and before the cooldown is applied**: a name in cooldown still has its sigma252 and still counts in the median. A name without 252 returns has no sigma252 and is never proposed. **median252 = the median of sigma252 over ALL of those names** (an even count: the mean of the two middle values). A name is **calm if sigma252 <= median252** (a tie at the median is calm). Only calm names may be proposed: among them drop the names in cooldown, keep r12 > 0 (and every other condition above), rank by s, propose the top 25 (fewer if fewer qualify; never padded with non-calm names). A unit test pins that a calm name in cooldown is not proposed and does not change the median.
- **Universe:** shared eligibility, no overrides.

## 3. Why

- The question: **does the any-day momentum rule restricted to the calmest half of the eligible stocks find T1 significant and meet all five gates?** The filter is the single change; nothing is tuned.

## 5. The baseline pool question (decided by the owner; stated plainly)
**The random pool is NOT restricted to calm stocks** (the same owner decision as for momentum_calm). The pool is the any-day pool rule C above. So the calm filter is part of the strategy's selection and **any benefit of simply holding calm stocks counts as the strategy's edge** in T1 (the trade's R minus the mean R of its random draws), not as something the baseline already has. A T1 pass would therefore not show that momentum works inside the calm half; it could come from the calm half alone. Changing the pool later is a new trial.

## 6. The honest note
- This is **the eleventh look at the same ten years** of data; **K = 1 counts only this family** and does not carry the earlier trials. **A pass would be weak evidence.**
- **The any-day rule already failed T1 in family_batch5 (adjusted p 0.4236 and 0.4270).** The calm filter changes which stocks are picked, so this trial is not a repeat, but a failure of T1 here would not be surprising.
- **The filter and the cooldown may leave few candidates**: on any session the candidates are the calm names with r12 > 0 that are not in cooldown. The overlap check (counts only, 118 sampled sessions: the first session with a 252-session window and every 21st after it; `OVERLAP.md`): the median number of calm names with r12 > 0 was 94 (min 33, max 247) and in no sampled session fewer than 25; it samples one session in 21, so it does not show every session.
- **The calm filter may leave the stocks nearly the same as plain any-day momentum.** The mean overlap of the 25 picks with plain riskadj_momentum_daily's 25 (pure top 25, no cooldown, slots or cash) is **0.355** (median 0.32, min 0.04, max 0.84), so on average about 9 of 25 picks are shared. The overlap says nothing about how the returns differ.
- **No tuning.** The median cut-off is fixed now; any other cut, window or volatility measure is a new trial. The overlap threshold 0.85 that decided whether this text would be written was fixed before the number was seen.
- With K = 1 the Max-T step-down is the single test.

## 9. Limitations (additional to the earlier texts, which apply in full)
The BE/BZ sell model is an assumption. sigma252 looks backward from the signal date and a calm name can turn jumpy. The median is taken over the shared-eligible names that have 252 returns, a thin set in the first signal months (about 140 to 200 names in 2017). A flat series has sigma 0 and counts in the median. The filter changes which names fill the 12 slots and the sector spread, so the trade count and the invested share differ from plain any-day momentum in a way not forecast here (the trade rate 8.1 is the plain rule's slot arithmetic). Every session now evaluates sigma252 for every eligible name, which makes the run slower than the plain any-day run. No dividends, no historical ASM/GSM, incomplete sector map and EQ-only buying, as in the earlier texts.
